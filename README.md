## ✨ Features

- Personal expenses, income, wallets (Cash / Bank / JazzCash / …), loans & budgets
- Group expenses with fair splitting — each member sees **only their own share**
- PIN lock, dark & light theme, English / Urdu, 47 currencies
- Works fully offline — all data stays on your device
- **Optional Google Drive backup** — backs up to *your own* Drive and restores on any phone with the same email
- Built-in self-updater — the app checks this page and tells you when a new version is ready
- Ad-supported (one ad when saving an entry, occasional dismissible banner); ad-free unlock code available from the owner

## 🔒 Privacy — the short version

- All data you enter stays **on your device**.
- Google Drive backup (optional) goes **only to your own Google Drive** — the developer **can never see anyone's data**.
- Ads are served by Unity Ads (and Google AdMob where enabled); no financial data is shared with anyone.

Full policy: [PRIVACY.md](PRIVACY.md)

## 🔄 How updates work

The app quietly checks [`version.json`](version.json) on this site at most once a day. When a new version is released, users see an in-app notice with an Update button — no Play Store needed.
